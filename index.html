Importante sobre privacidad

El dashboard es una demostración estática. Los cambios se guardan en este navegador y no se sincronizan entre equipos. No cargues datos personales ni contables confidenciales en una web pública. Para uso profesional se requiere autenticación, base de datos segura y copias de respaldo.
